# Architecture decision records

An ADR records one decision. Once its status is `accepted`, it is immutable: the write guard refuses edits. To change a decision, write a new ADR with `Status: proposed` that supersedes or amends it (skill `propose-adr`).

**Acceptance rule:** a proposed ADR becomes accepted when the human accepts it. <Optional: or by default at the close of the next iteration if the human has not objected.>
