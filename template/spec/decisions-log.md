# Decision log

Every decision taken without a human, appended in order (skill `log-decision`). Never rewrite or delete an entry; a later entry can reverse an earlier one and must cite it.

```
### YYYY-MM-DD · I<N>-T<NN> · Short title
Finding: ...
Options: A (the simplest), B (the most complete).
Choice: A, because ...
Impact: ...; proposed ADR: no | ADR-NNNN.
```
