# Escalations

Reserved decisions prepared by agents for the human (skill `escalate`). To decide, fill the `Decision:` line; the next agent applies it and changes the status to `[decided]`.

```
## [open] YYYY-MM-DD · I<N>-T<NN> · Title
Context: ...
Options: A ...; B ...
Recommendation: A, because ...
Prepared: ...
Decision: (to be filled by the human)
```
