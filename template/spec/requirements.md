# Requirements

One requirement per entry. Identifiers never change and are never reused; a dropped requirement is marked `withdrawn`, not deleted.

```
### REQ-001 · Short title
Priority: build order only (1, 2, 3).
Statement: the system shall ...
Acceptance: how a test or a command shows it holds.
Status: active | withdrawn
Source: optional, where it came from (an imported PRD section, an issue)
```

`node .claude/scripts/check-spec.mjs` checks this format.
